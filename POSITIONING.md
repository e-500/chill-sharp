# ChillSharp Positioning

## Core promise

Make your data useful without giving it away.

## Category

Permission-first data infrastructure.

## What ChillSharp does

ChillSharp turns an existing .NET data model into controlled interfaces that applications, people, and AI can use without surrendering unrestricted database access.

It gives teams a way to expose the right data to the right consumers while preserving permissions, schema consistency, and operational control.

## Primary jobs

1. Build an API
   - Turn an existing model into a usable API.
2. Build an application
   - Give an application controlled access to the data it needs.
3. Connect AI
   - Give AI useful data without giving it unrestricted database access.
4. Share data
   - Expose selected data to other systems while keeping control.
5. Build data-driven experiences
   - Create applications around one consistent model, permissions layer, and API surface.

## Core audience

Developers building applications and services around existing data, especially teams that need governed access and a clear boundary between data ownership and data consumption.

## Technical foundation

ChillSharp is built on .NET and the data model you already own:

- EF Core
- ASP.NET Core
- schema metadata
- authentication and authorization
- API generation and query patterns
- client access
- realtime updates
- AI-ready interfaces such as MCP

These are implementation mechanisms. They are not the product story itself.

## What ChillSharp is not

- Not a database
- Not an ORM replacement
- Not a generic API framework
- Not an AI platform
- Not a replacement for application logic

ChillSharp provides the infrastructure between your data and the things that need to use it.

## Preferred vocabulary

Use:

- controlled access
- useful data
- permissions
- data model
- application
- AI context
- governed interfaces

Avoid:

- generic CRUD platform
- data without boundaries
- unrestricted database access
- feature pileup as positioning
- "we do everything" language

## The sentence to keep stable

ChillSharp helps developers turn their existing data into controlled capabilities that can be used by applications, people, and AI.
