# How To Build `chill-sharp-ts-client`

From [`extra/chill-sharp-ts-client`](/c:/source/personal/chill-sharp/chill-sharp/extra/chill-sharp-ts-client):

```bash
npm install
npm run build
```

To publish a `.tgz` archive to the shared npm folder:

```powershell
.\publish-to-shared-folder.ps1
```

Default shared folder:

```text
C:\source\npm-shared
```
