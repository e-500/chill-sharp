# How To Build `chill-sharp-py-client`

From [`extra/chill-sharp-py-client`](/c:/source/personal/chill-sharp/chill-sharp/extra/chill-sharp-py-client):

```bash
pip install -e .
python -m compileall chillsharp_py_client
```

This package is not published to the npm shared folder. Its local [`publish-to-shared-folder.ps1`](/c:/source/personal/chill-sharp/chill-sharp/extra/chill-sharp-py-client/publish-to-shared-folder.ps1) script is intentionally a no-op.
