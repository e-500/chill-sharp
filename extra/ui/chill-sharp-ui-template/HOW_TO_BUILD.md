# How To Build `chill-sharp-ui-template`

From [`extra/ui/chill-sharp-ui-template`](/c:/source/personal/chill-sharp/chill-sharp/extra/ui/chill-sharp-ui-template):

```bash
npm install
npm run build
```

This package is a private application shell. It is not published to the shared npm folder, and its local [`publish-to-shared-folder.ps1`](/c:/source/personal/chill-sharp/chill-sharp/extra/ui/chill-sharp-ui-template/publish-to-shared-folder.ps1) script is intentionally a no-op.
