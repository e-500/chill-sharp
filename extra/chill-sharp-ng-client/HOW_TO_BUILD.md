# How To Build `chill-sharp-ng-client`

From [`extra/chill-sharp-ng-client`](/c:/source/personal/chill-sharp/chill-sharp/extra/chill-sharp-ng-client):

```bash
npm install
npm run build
```

This package depends on the local `chill-sharp-ts-client` source through `file:../chill-sharp-ts-client`.

To publish a `.tgz` archive to the shared npm folder:

```powershell
.\publish-to-shared-folder.ps1
```
